# Dreamy Oracle Tarot

## V1.0.0 — Soft misty oracle tarot PWA
ไพ่ทาโรต์สไตล์ออราเคิลนุ่มฝัน สำหรับไบคัง — เพื่อความบันเทิงและสะท้อนคิด

### Features
- **จั่ว 1 ใบ** หรือ **3 ใบ (อดีต / ปัจจุบัน / อนาคต)**
- ไพ่ครบ 78 ใบ (Major + Minor) ความหมายแนว Rider–Waite ภาษาไทย (อบอุ่น สะท้อนคิด)
- ตัวเลือกไพ่อัพไรท์ / กลับหัว
- การ์ดแบ็ค + หน้าไพ่สไตล์ CSS/SVG (ไม่มีศิลปะลิขสิทธิ์)
- แตะเพื่อจั่ว + แอนิเมชันพลิกนุ่มๆ
- ฟอนต์ **Kanit** ทั้งไทยและอังกฤษ
- Mobile-first PWA (manifest + service worker + icons)
- Disclaimer: เพื่อความบันเทิง / สะท้อนคิด — ไม่ใช่คำแนะนำทางการแพทย์หรือกฎหมาย

**Live:** https://whytyx.github.io/oracle-tarot/
